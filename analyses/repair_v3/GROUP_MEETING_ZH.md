# 面向科研智能体的"诚实可信—新颖度"外部治理组件

日期：2026-11-17

> **标注说明**：正文标有 ⚠ 的数字受已知测量问题影响，不能直接作为结论使用。问题清单与影响范围见 **3.6**。

---

## 研究背景与主要结论

1. 科研智能体的评价重心已从"端到端生成能力"转向"结果可验证性"。现有系统在可复现性与学术诚信两个维度上均存在显著缺口。
2. 直接引入严格的审查机制，会使"诚实"与"新颖"退化为零和关系：判定宽松时放过低质量提案，判定严格时误杀高价值提案。
3. 本文的做法是将治理逻辑从系统内部解耦，实现为一个与模型、与 Agent 无关的外部组件。该组件承担两项约束：**每条关于已有工作的断言必须落到给定证据上**；**未被证实的差异必须显式转化为待检验问题**。
4. 已完成三组干预实验。初步结果是：外挂对三个来源的过度断言均有压制（3 题预实验，方向一致但不进主表）；在 Direct 宿主的 40 题上，外挂相对强基线未测出净增益；对 AI-Scientist 与 E-DARA 产物的干预实验尚未开展。

# 第一部分　调研

## 1.1 领域现状：可验证性缺口

| 数据 | 来源 |
|---|---|
| 24 个自主科研系统中，83% 开源代码；仅 38% 公开随机种子或执行轨迹，仅 38% 报告过任何形式的新颖度验证 | 调研报告 §1 |
| SciIntegrity-Bench：7 个前沿模型在 **34.2%** 的场景中产出方法论有缺陷或显式造假的结果 | 调研报告 §1 |
| MLR-Bench 抽检：约 **80%** 的智能体实验结果存在编造或无效验证 | 调研报告 §1 |

上述数据表明，问题不在单个模型的输出质量，而在整个研究流程缺少可验证的约束结构。

## 1.2 "诚实—新颖度"权衡的四种机理

| 机理 | 描述 | 实证依据 |
|---|---|---|
| **提示词极化**（判松了乱放行，判紧了全杀掉） | 默认提示下存在乐观偏见，严厉提示下转为保守崩塌，审查器缺乏稳定的方法论鉴别力 | SoundnessBench（1,099 份 ICLR 提案）：标准提示假阳性 **74.0%**；严厉提示假阳性降至 19.9%，但高价值提案召回率降至 **36.1%** |
| **整体否决**（一处撞车就毙掉整篇） | 科研发现多建立在"继承—重组—边界拓展"之上，以"核心主张被覆盖"为由整体否决，会系统性地误杀增量与组合创新 | ClaimNov：时间截点后被人类实现的想法被误杀 **11.8%** |
| **新颖度漂移**（嘴上认了，手上不改） | 模型可正确引用先验文献，却在贡献声明中将该机制据为己有；被要求收缩主张时，又会整体迁移研究问题、删除有效内容 | RINI 的"识别不等于归因"与"重定位行为" |
| **信息过载与二值失败记忆**（给太多反而同质化；失败一次就永久否决） | 背景信息过载抑制跨域联想；失败记忆库采用一票否决，会导致想法谱系灭绝 | BVSR；Failure Banks 相关研究 |

## 1.3 外部挂载范式的四种介入时机

把同一个检查放在不同阶段，效果完全不同：事后审稿只能扣分，事前约束才能改变产出。调研按介入时机把现有做法分为四类。

| 时机 | 要解决的问题 | 通俗做法 | 代表工作 |
|---|---|---|---|
| 生成前 | 背景给得太满，模型只会沿常规套路想 | 先不给完整题目和数据集，只给抽象的问题，促使其跨领域联想；同时把"以前失败过什么"整理成提醒，但只记录"观察到失败"，不判定"这条路不可行"，避免误杀 | BVSR、Negative Knowledge |
| 生成中 | 方案写到一半就开始自圆其说 | 要求先把"什么结果算失败"写死，再往下做；假设的每次状态变化都记进一份只能追加、不能改写的日志 | Lit2Test、HEP |
| 执行期 | 实验失败后一律重试，既浪费预算也学不到东西 | 先列出几种可能的失败原因并逐条评估，再按固定规则决定改代码、改数据还是放弃 | SAGE、CARTOGRAPH |
| 生成后 | 整篇重写会连带删掉有效内容，数字也说不清来源 | 只改少数几处具体句子并限制改动数量；每个数字都要能对上实验记录，对不上的标出来 | ClaimNov、RINI |

六个代表工作，按"发现的问题 → 采取的做法"说明：

- **RINI**：发现模型会"引用了某篇论文，却在贡献声明里把该论文的机制说成自己的"。做法是逐句核对观点是否已被前人提出，若已被覆盖即要求明确归功；需要修改时最多改动 4 处，不重写全文。
- **ClaimNov**：发现"整篇只要有一处撞车就否决"会误杀组合创新。做法是把新颖度拆到一条条主张上分别判定。
- **BVSR**：发现提供的背景越详细，产出的想法越同质。做法是在生成前主动压缩信息量。
- **CARTOGRAPH**：发现"尚不知道"经常被当作"已经知道"处理。做法是把未决项转成"下一步做哪个实验来区分"。
- **SAGE**：发现失败不分型、一律重试既浪费预算又无助于改进。做法是先归因、再按类型路由。
- **Lit2Test**：发现方案在事后怎么解释都成立。做法是事前把"什么结果能否定该想法"写进契约。

## 1.4 现有研究的空白

前述四类机理说明：问题不是"审查不够严"，而是审查的粒度与时机不对。调研归纳出四个空白，分别对应治理链条上的四个环节——判什么、怎么判组合创新、判完怎么用、怎么接进别人的系统。

**① 没有把"事实 / 假设 / 未知"分开的组件**

- 现状：ClaimNov、RINI 只处理立项阶段的文献归因，SAGE、CARTOGRAPH 只处理实验阶段的日志与数值溯源。没有任何组件负责判定"一句话属于哪一类"。
- 后果：同一句话会被两种方式误判。当作事实时，它意味着"前人已做过"，创新被否；当作假设时，它意味着"可以继续探索"，失实被放过。审查器只能在整体上偏向一端，于是出现"判松了乱放行、判紧了全杀掉"。
- 补上之后的意义：**严格只作用于事实，宽容只作用于假设**。事实必须归功、必须有据；假设允许未证实，但必须写明如何检验。诚实与新颖不再是全局二选一，而是按陈述类型分别处理。

**② 没有跨多篇文献的组合归因**

- 现状：RINI 明确只针对"单一决定性先验文献"，跨文献的分布式证据归因被列为未来工作。
- 后果：真实的创新大量是"A 的方法 + B 的设定"。现有工具看到 A 与 B 各自被做过，就倾向于判定该组合也被做过，直接否掉。ClaimNov 的实测显示，这种整体否决会让 11.8% 后来被人类实现的想法被误杀。
- 补上之后的意义：可以判定"组合本身是否被覆盖"，并把未被覆盖的部分保留为余项，而非整篇否决。**组合创新从"容易被误杀"变成"可以被单独检验"**。

**③ 事前契约与事后失败记录没有接上**

- 现状：Lit2Test 的可证伪契约停留在静态评分；失败记忆库也未与该契约绑定。
- 后果：立项时写下的"什么结果算失败"，实验失败后无人核对。系统分不清"想法不成立"与"实现有缺陷"，同类失败反复出现且不积累。
- 补上之后的意义：失败可以归因到具体条件，并回流为下一次立项的约束。**一次失败从"浪费一次预算"变成"留下一条可复用的约束"**。

**④ 缺少标准化的接入形态**

- 现状：现有实现多为论文附带代码，接口各异；生态正向 MCP 演进，但尚无现成组件。
- 后果：不同系统之间无法用同一套治理组件比较，"与模型无关、与 Agent 无关"无法被验证。
- 补上之后的意义：同一组件可挂载到多个系统上做对照。**这也是本文三宿主实验得以成立的前提**。

**本研究的定位**：①②为直接目标（三态分流、组合余项分析）；③为部分覆盖（规范缺陷已接入，失败记忆库未做）；④不在实现范围内，但三宿主对照本身是对"可迁移"的一次验证。

# 第二部分　组件设计

## 2.1 E-DARA 的治理原则

1. **事实、假设与未知分离**：阶段评审不要求假设已被证实，但要求明确区分已知事实、待检验假设与未决依赖。
2. **判断绑定证据**：文献准入、证据原子、版本与字段引用；评审意见须落到具体版本与字段。
3. **分型路由**：局部修订、补充证据、回上游修改设计、记录外部限制，四类问题走不同处理路径。
4. **不可变版本与跨阶段责任**：每次修订保留父版本，未解决的义务挂账并跨阶段继承，不以文字润色替代。

## 2.2 外部治理组件的六个部件

该组件仅依赖"候选文本 + 给定文献"，不依赖宿主内部状态，因此可挂载于任意模型或 Agent 之外。

| 部件 | 功能 | 对应空白 |
|---|---|---|
| **三态审计** | 将候选拆分为 prior_facts（事实）/ prospective_hypotheses（前瞻假设）/ unknown_dependencies（未决依赖），并输出平滑分与过度断言标记 | ① |
| **贡献审计** | 每条贡献区分为 core / component，判定 covered / distinct_hypothesis / unresolved；要求 proposal_span 与 evidence_quote 逐字可核对 | ① |
| **组合余项分析** | 判定"A 被覆盖且 B 被覆盖"是否等价于"A+B 被覆盖"，识别仍未被覆盖的组合余项 | ② |
| **规范缺陷定位** | 五类缺陷：超参阈值、数据切分、基线对齐、失效区间、指标与决策规则；区分 blocking 与 recommended | Lit2Test 契约 |
| **有界修复** | 每轮最多 4 处 span 局部替换（`MAX_PATCHES_PER_ROUND = 4`），另设独立的字段级澄清追加通道 | RINI 的微创原则 |
| **反馈路由** | 五个动作：regenerate / local_patch / clarify / seek_evidence / retain_and_test | SAGE 的分型路由 |

六个部件中，三态审计是地基：后续每个动作作用于哪一类陈述，由它决定。

术语说明：

- **core / component**：核心贡献 / 复用组件。判断一条贡献是你提出的，还是只是用了别人的方法。
- **covered / distinct_hypothesis / unresolved**：已被前人覆盖 / 存在可检验的实质差异 / 无法判定。
- **五个动作**：regenerate（重新构思）/ local_patch（局部改写）/ clarify（补充澄清）/ seek_evidence（补充检索）/ retain_and_test（保留并进入验证）。

# 第三部分　实验

## 3.1 实验设置

| 编号 | 宿主 | 题量 | 对照条件 | 检验的问题 |
|---|---|---:|---|---|
| E1 | 三个来源：Direct / AI-Scientist v2 / E-DARA 导入文本 | 3 | 原稿 vs 接外挂 | 外挂能否跨来源生效 |
| E2 | Direct（deepseek-flash 直出） | 40（15 核心 + 25 新题） | 原稿 / 自我改写 / 检索后改写 / 局部外挂 / 完整外挂 | 外挂相对强基线的净增益 |

三组实验共用同一套判定：三轴（诚实 / 可信 / 新颖）各判 pass / fail / unresolved，三轴全通过才计联合达标；同一题的所有臂共用一份冻结证据池。

## 3.2 E1：3 题跨来源预实验

**指标**：过度断言＝每篇平均"把未证实内容表述为已知"的处数（越低越好）；规范完整度＝规范缺陷定位给出的完备度（越高越好）；方法保留＝修改前后方法字段的词项重合度（越接近 1 保留越多）；新颖度＝经完整性过滤后的分值（0–1）。

| 来源与条件 | 过度断言 ↓ | 规范完整度 ↑ | 方法保留 ↑ | 新颖度 ↑ |
|---|---:|---:|---:|---:|
| Direct 原稿 | 0.067 | 0.35 | — | 0.524 |
| **Direct + 外挂** | **0.026** | **0.43** | 0.98 | **0.721** |
| Direct + 自我改写（对照） | 0.077 | 0.31 | 0.69 | 0.510 |
| ⚠ AI-Scientist v2 原稿 | 0.195 | 0.24 | — | 0.000\* |
| ⚠ **AI-Scientist v2 + 外挂** | **0.075** | 0.28 | 0.99 | **0.851** |
| ⚠ E-DARA 原稿 | 0.242 | 0.39 | — | 0.000\* |
| ⚠ **E-DARA + 外挂** | **0.022** | 0.32 | 0.99 | **0.469** |

\* 新颖度为完整性过滤后的分值；原稿的 0.000 表示被过滤清零，不等于没有新颖性。

**解读**

1. 三个来源的过度断言均被压制，方向一致；修改只动少数句子，方法保留 0.98–1.00。
2. Direct 一行是干净输入：新颖度由 0.524 升至 0.721，即压低过度断言的同时没有牺牲新颖度。
3. 对照组自我改写把过度断言压到 0.077，但方法保留仅 0.69、新颖度降至 0.510——以丢失方法细节换取表面完整。

**问题**：AI-Scientist 与 E-DARA 四行的原稿值受引用编号剥离影响（P1–P3），其"改善"含可信度恢复成分，不能读作内容质量的提升。本组仅 3 题，只作方向性证据。

## 3.3 E2：40 题 Direct 五臂

**指标**：P / F / U 为通过、失败、未决；未决指证据不足或无法核对，既不计通过也不计失败；三轴全过才计联合达标。

| 臂 | 联合达标 | 诚实 P/F/U | 可信 P/F/U | 新颖 P/F/U |
|---|---:|---|---|---|
| 原稿 | 19 / 40 | 21 / 19 / 0 | 39 / 0 / 1 | 33 / 5 / 2 |
| 自我改写 | 17 / 40 | 19 / 19 / 2 | 39 / 0 / 1 | 30 / 4 / 6 |
| 检索后改写 | **21 / 40** | 23 / 17 / 0 | 39 / 0 / 1 | 32 / 3 / 5 |
| 局部外挂 | 19 / 40 | 21 / 14 / 5 | 34 / 0 / 6 | 32 / 3 / 5 |
| 完整外挂 | 17 / 40 | 19 / 19 / 2 | 39 / 0 / 1 | 34 / 4 / 2 |

**解读**

1. 五臂落在 17–21，差距 4 题，未分离；最高为检索后改写，不是外挂。
2. 外挂与原稿的差别主要是分布形态：局部外挂多出 5 题未决（多为引文定位失败），完整外挂新颖度略高 1 题。
3. 可信轴 34–39/40，已饱和，不具区分力。

**问题**：40 题为两次运行合并，证据池与插件版本均不同（P4、P8）；判定方差 28%（P5）。因此只能得出"未测出差异"，不能得出"没有差异"。

## 3.4 评测口径修正

报告中的数字与更早结果不可直接比较，原因有二：早期判定中 225 个维度有 69 个因引用定位失败被降为未决（其中 22 个仅差首尾引号）；旧标准下诚实轴通过率 87.6%，几乎不区分对象，收紧后为 41.8%。

即便修正后，三次抽样的联合判定翻转率仍为 28%，断言抽取重合率 0.55。**任何 1–3 题量级的臂间差异都不可信。**

### 3.4.1 修复后的对照（单列）

修复方式：导出改用可解析的匿名编号，并把原生文献注入同一证据池。结果单列，不与上表混合比较。

| 指标 | 修复前（3 题） | 修复后（9 份） |
|---|---|---|
| E-DARA 每篇过度断言数 | 5 / 3 / 3 | **0** |
| E-DARA 查无此文献断言占比 | 抽样 4 / 6 条 | **0.00** |
| E-DARA 断言支持率 | 未测 | 0.21 [0.07, 0.36] |

**解读**：证据补齐后，过度断言与"查无此文"均归零，说明原高值来自证据未随文本传入；支持率仍偏低，因正文编号与池中编号空间不一致。

**问题**：E1 的 3 题未按修复后口径重跑，两组只作方向对照（P1 已修、P2 未修）。

## 3.5 本节能支持与不能支持的结论

**可以支持**：

1. 外挂在 3 题、三个来源上均降低过度断言，且方法保留 0.98–1.00；自我改写则以方法细节丢失（0.69）换取表面完整。⚠ 该组为 3 题预实验，其中两行输入存在证据剥离（P1–P3，见 3.6），仅作方向性证据。
2. 在输入干净的 Direct 宿主上，外挂未牺牲新颖度（0.524→0.721），而自我改写使其下降（0.524→0.510）。该结论仅限 Direct 一行，跨来源因 P2 不可用。
3. 在 Direct 宿主的 40 题（15 + 25）上，外挂相对强基线未测出净增益。
4. 可信轴在现有判定标准下饱和，不具备区分力。

**不能支持**：

1. 外挂对任意宿主有效——除 E1 的 3 题外，AI-Scientist 与 E-DARA 的稿子均**未接受过外挂干预**，只做过审计。
2. 任何 1–3 题量级的排序。
3. 外挂"无效"——40 题上的零差异与仪器方差同量级。

下表列出本报告中所有已知影响数字解释的问题。正文中带 ⚠ 的数据对应其中的条目。

| 编号 | 问题 | 影响范围 | 后果 | 状态 |
