# 科研提案外评协议 v1

本协议用于评估同一外挂对 Direct、AI-Scientist 和 E-DARA 冻结提案的改稿增益。**评审模型给出可核查的语义判断，程序验证原文和证据并计算分值。** 诚实、可信、新颖分别评价和汇报。

## 1. 试验比较与评委输入

| 设置 | 常规组 | 外挂组 | 共同条件 |
|---|---|---|---|
| 等条件主实验 | 根据审阅任务和证据自行诊断，提出局部修改 | 用结构化治理审计诊断，再提出局部修改 | 同一原稿、证据、编辑模型、补丁执行器和调用上限。每臂最多一轮、四处修改，追加澄清占一个修改名额。 |
| 完整外挂比较 | Retrieve-and-Revise，检索后常规改写，可重构方案 | 完整反馈路由，可搜证、澄清、局部修改或重构 | 同一原稿、初始证据、编辑模型、检索入口和资源上限。记录实际使用的调用、检索和编辑成本。 |

每项比较以同一份原稿为配对单位，原稿提供两组共同的计分起点。运行前冻结样本清单、原稿阶段和版本、正文哈希、任务范围、资源上限、证据规则、评委模型版本和提示词。原稿缺失按宿主和 topic 报告。修订失败时保留最后有效稿作为该臂的结果，并记录失败。

原文保留可核对的字段和引文映射。盲化只匿名化身份和引用编号，保持原意、数字、条件及实验状态。正文缺项保留为空。评委只看匿名稿件、任务说明和统一评价证据，外挂内部审计留作机制诊断。

证据包区分两种用途。**出处核对**使用可定位的来源与原文段落。**先验对照**额外要求证据版本能确认早于 topic 截止日，并与核心主张相关。日期未知或只能定位到截止当年的来源可用于出处核对，先验对照需补足日期。等条件组使用同一冻结证据。完整比较的新增检索来源在两组出稿后按同一规则验收，形成两组共享的评价证据包。

## 2. 三轴评分规则

### 2.1 诚实与证据归因

1. **冻结断言清单。** 外评在查看修订稿前，从原稿提取可按原文定位的关键原子断言，给每条分配固定 ID。纳入会影响研究缺口、已有贡献归属、方法前提或实验结果的事实性陈述。标明为假设、预期结果或未知依赖的内容依其实际含义判读。重复表达同一断言时合并计数。
2. **判定原稿状态。** 每条标记为 `有据`、`有明确缺陷` 或 `证据不足`。缺陷包括陈述被文献明确反驳或超出文献适用范围、错误归功，以及有依据认定为把预测写成已观察结果。文献缺失、引用无法解析、可见段落覆盖不充分分别记录原因。当依据不足时，标记为 `证据不足`。
3. **追踪修订。** 原稿断言依据固定 ID 与各版本对齐，原句和其证据相同时复用判定。每条缺陷在事实改正、归因正确或未验证预测合理还原为假设后计一次纠正。单纯删除单列。把已有反证的事实只改成语气保守的说法，保留为未纠正或未决。另从实际改动处检查新增断言和原先有据、修改后出现的缺陷。每条新缺陷只计一次。

设 `K` 为原稿冻结的关键断言数，`R` 为已确认纠正的缺陷数，`E` 为新引入的缺陷数。

`净纠偏 = (R − E) / max(1, K)`

例如，原稿有 8 条关键断言，修好 2 条、引入 1 条新缺陷，净纠偏为 `1/8`。原稿的净变化为 0。两臂的 `K` 相同，一并报告 `K、R、E`、删除数和未决数。原判证据不足、修订后得到支持的项目单列为证据覆盖改善。评测端恢复引用映射时，先用修复后的公共证据重判原稿和修订稿，调整统一的计分起点。

借用断言与证据关系、引文支持与覆盖的评测结构。锚点核验交给程序，文献是否支持陈述交给模型判断。 [SciFact](https://aclanthology.org/2020.emnlp-main.609/) · [ALCE](https://aclanthology.org/2023.emnlp-main.398/)

### 2.2 可信与实验设计

评委先从原文标出核心假设、具体测试、区分性对照、指标和支持或判败结果，再判断这些要素之间的关系。区分性对照可以是比较组、消融或能排除主要替代解释的等效设计。指标须对应假设涉及的效应，支持与判败结果须对应同一项检验。

| 等级 | 规则 |
|---|---|
| `0` | 缺核心假设或可执行描述的具体测试。 |
| `1` | 有核心假设和具体测试，但对照缺失或无法区分主要替代解释，或指标与假设所关心的效应不匹配。 |
| `2` | 对照和指标能区分主要解释，但支持结果或判败规则缺失、含糊，或两者无法构成可解释的决策。 |
| `3` | 在 `2` 级所要求的对照和指标基础上，明确给出可区分的支持及判败结果，且两者均对应核心假设。 |

模型逐项返回 `核心假设明确`、`具体测试存在`、`对照具有区分力`、`指标匹配`、`支持和判败规则有效` 的判断及原文依据，取值为 `是`、`否` 或 `未决`。程序按表从 `0` 级向上判断。关键判断未决且会改变等级时，整轴标为未决。对每份稿件报告修订前后等级和差值，用等级升降比较两臂。技术、数据和预算可行性另列。仅添加「若无提升则失败」之类的句子时，仍需验证其对照、指标和决策关系。补齐一个能排除主要替代解释的对照可以提高等级。

采用 Lit2Test 的假设、测试、指标和支持／判败结果之间的关系作为评价结构。既有提案以原文定位适配该结构。 [Lit2Test 评测协议](https://arxiv.org/html/2608.22948v1#S3)

### 2.3 新颖与实质贡献

先用原文锚点对齐前后版本的核心贡献，再逐项对照同一批符合截止日要求的相关文献。模型给出 `已覆盖`、`有实质差异` 或 `证据不足`，写出最接近的先验、对照段落及所处问题、机制或条件的具体区别。仅换名称、把已知组件改成自己的表述、或只补文献引用时，按核心内容是否变化判定。

| 分值 | 规则 |
|---|---|
| `+1` | 新增或实质强化一项相对先验有据的核心差异，同时保留有价值的原核心差异。 |
| `0` | 核心贡献相同，或在证据充分时可判定无实质增损。只补引文、纠正归因、讲清已有差异均记 `0`，相应收益记在诚实或贡献定位诊断。 |
| `−1` | 丢失原有实质差异，且可确认修订稿缺乏有据的替代贡献。 |
| `未决` | 关键近邻文献不足以判断变化，或同时有新增和丢失、现有依据无法判定净变化。 |

每份修订稿相对同一原稿定级，再比较两臂的等级。新版新增的区分性实验可提高可信等级，已有研究内容仅因证据补齐而变得更可核对时，单列为贡献定位改善。三轴独立计分。

借用 ClaimNov 的逐贡献覆盖判断和 RINI 的剩余差异核对。 [ClaimNov](https://arxiv.org/html/2610.36511v1) · [RINI](https://arxiv.org/html/2609.33284v1#S6)

## 3. 自动校验、复核与汇总

- **模型输出。** 每条判断保存稿件版本、评价项 ID、原文位置、状态、证据 ID、逐字引文和理由。涉及实验设计的判断指向实际测试和决策内容。缺失项注明检查过的字段。涉及先验覆盖或事实支持的判断指向对应文献段落。
- **程序校验。** 检查原文位置与引文可定位、证据 ID 与来源匹配、日期与用途合规。允许纯格式的归一化。校验失败记为 `评测失败`，与 `证据不足`、`评委分歧` 分开。稿件原文明显缺少规定内容时，按相应维度的计分规则处理。相同原文和同一证据下，同一评价项复用判定。
- **换序复核。** 改稿比较遮蔽宿主和试验臂，互换两份稿件的位置复评。按真实稿件 ID 对齐后，语义判断一致且通过校验才使用对应标签；两次有实质分歧则记未决。两次响应用于复核同一对稿件。
- **汇总。** 保存逐稿分值和两臂配对差。差值符号给出外挂胜、负或平。影响比较方向的证据不足、分歧或评测失败列为未决。保留每轴胜、负、平、未决总数。描述性净胜率为 `(胜数 − 负数) / 已判定配对数`，平局计入已判定配对。主汇总先对每个 topic 的已判定配对取均值，再对 topic 等权平均，以 topic 为单位配对重采样给出 95% 区间。全未决的 topic 单列，敏感性分析把未决分别按外挂全胜和全负纳入，检查方向能否逆转。另报各宿主、共同 topic 以及 E-DARA 的 Plan／Proposal 分项。改善结论逐轴给出。成本、改动量和贡献定位单列。

## 4. 正式评分前的验收

每轴冻结 **12 对方向已知的实质变化样例**，另设 **6 对只有表达变化的对照**。优先使用发布的 benchmark 判例，补入本地的引用映射和渲染案例。按正式评测流程和同一评委配置测试，表达对照也送评委实际判定。评委至少判对 **10/12** 个实质方向，且至少将 **5/6** 个表达对照判为持平，该轴才发布正式效果数字。未决和格式失败保留在验收分母。

| 检查 | 预期结果 |
|---|---|
| 将正确支持某断言的来源替换为明确反驳该断言的来源 | 诚实轴识别错引，保留两侧的出处证据。 |
| 仅修复评测导出时丢失的引用映射 | 原稿和修订稿同步恢复出处核对，从修复后的共同基线计分。 |
| 只补准确归因，核心机制和测试相同 | 可改善诚实或贡献定位，新颖度变化为 `0`。 |
| 原有对照混入主要替代解释，修订后加入能排除它的对照 | 其余条件满足时，可信等级升级。 |
| 旧机制只更名，或用无日期证据声称先验覆盖 | 更名没有实质增益；日期不足的证据不进入先验对照。 |
| 同内容换格式，或将评委引用改成原文中不存在的句子 | 前者判持平，后者记评测失败。 |

0–3 级可信量表、净纠偏公式和验收门槛为本轮协议约定。公开 benchmark 提供评价结构、判例与诊断方法。协议与校准清单在查看正式组间结果前锁定。 Lit2Test 冻结校准材料（论文 arXiv:2608.22948 的补充包，未随本仓库分发）
