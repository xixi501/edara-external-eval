# 科研提案外评协议 v1.2（v1 增补版）

本文件是 [EVAL_PROTOCOL_V1_ZH.md](EVAL_PROTOCOL_V1_ZH.md) 的增补版本，用于 2026-11-18 之后的同稿对照试验。**v1 原文保持冻结**，其绑定结果不因本文件改变；v1.2 只适用于 manifest 记录本文件哈希的新输出目录。未在本文件列出的条款沿用 v1。

改动原因：v1 的评委单次判断在两轮校准间有 7/54 案例翻转，诚实轴在 9–12/12 之间摆动，门禁结果由抽样噪声决定；同时 C 臂的规格缺陷诊断过于泛化，编辑只补通用对照，补不到对该假设决定性的那一个。

## A1 评委投票与校准

1. 每个「稿件对 × 轴」做 **3 次独立判断**：正序、倒序、正序重采样（temperature 0.2）。三次各自得到一个配对差。
2. 判定取多数：至少两次得到相同配对差才采用该差值；三次互不相同记 `judge_disagreement`；少于两次得到具体差值记 `insufficient_evidence`。
3. **校准与正式试验使用同一投票程序**。v1 中校准两次、试验两次的分歧不再允许。
4. 校准集仍为每轴 12 个方向已知的实质变化对和 6 个只有表达变化的对照，门槛为实质 ≥10/12 且表达 ≥5/6。未通过的轴不发布正式效果数字，只报告校准结果。

## A2 判定单位

两轮复核比较**同一对稿件的配对差**，不再比较各臂的绝对等级。两轮绝对等级不同但配对差相同，按该差值判定。绝对等级仍写入逐稿记录供核对。

## A3 未决与不确定性

诚实轴的未知宽度只计**不对称未知**：逐 claim ID 对齐，只有一侧为 `unknown` 而另一侧有确定标签时才计入带宽。两侧同为 `unknown` 相互抵消，不再压制零差值。带宽按 `|δ| ≤ 不对称数 / K` 判未决。

## A4 机械归一化

评委输出格式不统一时，程序先归一化再判定，不允许因单条格式问题作废整份比较。归一化包括：字段名漂移时按引文唯一定位字段；引用写作 `A1`、`A1: 原文`、`S… A3`、`{"paper_id","passage"}` 时解析为原文；`added` 中出现 `supported`/`hypothesis`/缺标签时忽略或丢弃；漏报的 ledger ID 按原句是否仍在稿件中补 `same` 或 `unknown`；删除但原句仍在改判 `same`；新增项与原稿重合则不计新增缺陷。每次修复写入 `repairs`。归一化只改机械一致性，不改语义标签。

## A5 治疗变更：假设特异性混淆项审计

C 臂与 E 臂的审计新增 `confound_audit` 头，B 臂与 D 臂不获得该诊断。

1. **审计内容**：针对核心假设，列出最多三个能产生同一观测的替代解释，为每个解释给出能分开二者的具体实验臂（基线、消融或匹配对照），并判定该臂在稿件中是 `present`、`absent` 还是 `ambiguous`。`present` 必须附原文锚点，否则降为 `ambiguous`。
2. **诊断顺序**：混淆项排在诊断字典第一位，先于证据、缺口与一般规格缺陷。
3. **编辑优先级**：存在 `status=absent` 的混淆项时，第一条规格澄清必须把 `discriminating_arm` 写入 `minimal_test` 或 `decisive_metric`。通用基线、改写措辞、或不能区分两种解释的相邻消融视为未处理。
4. **对照条件**：四处修改上限、同一编辑模型、同一证据包、同一补丁执行器不变。B 臂继续只接收常规审阅诊断，用于回答「结构化审计是否带来增益」。
5. **隔离**：外评评委只看到匿名稿件、任务和统一证据包，不读取审计诊断、混淆项或编辑理由。
6. **强制落实**：编辑返回后，程序检查其修改是否覆盖 `design_confounds.decisive_missing` 指定的那个实验臂（在 `minimal_test` 与 `decisive_metric` 中按关键词覆盖率判断）。未覆盖时用同一编辑模型做一次独立调用，只要求返回一条 `minimal_test` 追加（不超过 400 字符），点名该实验臂；这次调用使用独立的调用预算，不计入四处修改名额。重试结果仍未覆盖时记 `confound_enforcement.addressed=false`，按未处理进入结果分析。

## A6 编辑预算

补丁式追加的上限从 240 字符提高到 **400 字符**，对 B、C、E 三臂一致。追加仍计为一次修改，四条上限不变。

审计预算只统计实际执行的模型调用。一个臂复用其他臂已经保存的审计记录（同一稿件、同一证据）时，复用单独计量，不占用本臂预算。修改理由：25 份旧稿中 22 次追加被拒，长度全部落在 241–308 字符，属于上限过紧而非编辑越界。

## A7 记录与版本

manifest 记录本文件的路径与 SHA-256。协议、评委提示词、判读代码或治疗条件任一变化，必须开新输出目录，不得在旧目录上续跑。逐稿记录保留每次判断的原始响应、三次投票的差值、机械修复清单和未决原因。
