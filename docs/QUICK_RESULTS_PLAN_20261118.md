## 0. 目标与约束

**目标**：今天晚上和导师讨论，需要一组**经得起追问的初步结果**，不是「跑出显著为止」。讨论要能回答三件事：

1. 外挂目前到底有没有可检测的增益？
2. 如果有，增益来自哪个机制？
3. 下一步该把有限预算投到哪里？

**约束**：

- 时间：距讨论约 5–6 小时；今天可用的额外预算约 **$1–2**。
- 无人工标注资源；评委是单一模型（GLM-5.3-flash），三次重复采样，不是多模型。
- 没有干净的确认集：现有 38 份和 25 个 extension topic 都参与过此前的结果分析与设计决策。
- 今天不能重跑整套 38 份四臂，也不能做 60 题确认实验。

## 2. 今天下午刚做的零成本分析（事后分析）

把 0–3 级拆回五个检查项，按三次判断的多数票还原成 0–5 的检查项计数，再做配对：

| 比较 | 平均配对差（0–5） | 95% 区间（topic 重采样） |
|---|---:|---|
| C vs B | **+0.316** | **[+0.178, +0.478]** |
| E vs D | −0.132 | [−0.289, +0.000] |

逐检查项变化（多数票）：

| 比较 | control | decision | hypothesis | metric |
|---|---|---|---|---|
| C vs B | **+10 / −0** | +3 / −1 | 0 | 0 |
| E vs D | +1 / −3 | +1 / −1 | 0 / −2 | 0 / −1 |

两个要点：

- C 的增益是**机制特异**的：十个新增的「对照」检查项、零个丢失，直接对应混淆项审计与强制落实。
- E 的负向**依赖聚合口径**：等级级显著，要素级不显著。更准确的说法是「没有增益，且在对照和假设上有净损失」。

同时完成了 7 个 E 负例的语义核验：6 个是真实设计缺陷，1 个是评委 2:1 不稳定；没有证据支持「量表系统性惩罚改写」。

- A 是唯一能补「诚实轴完全没数字」这个硬缺口的；而且只影响诚实轴，不动已有两轴。
- D 让主结果从「+0.222」变成「+0.316 个检查项、集中在对照项」，机制故事更清楚。
- B 能把 Direct 样本翻倍，但延伸题参与过旧实验，只能标探索性；如果老师更看重「样本量」，可以加。
- C 是下一轮的事，今天做不完，也不应该拿新治疗当初步结果。

## 4. 需要外部评审者判断的四个问题

1. **同一天内，哪一个额外动作的信息增益最大、且不损害可解释性？** 是 A（补诚实轴）、B（扩 Direct 样本），还是都不做、只把现有结果讲清楚？
2. **要素级分析是事后分析。** 会议上应该把它作为主结果、辅助结果，还是干脆不放进主表？如果放，怎么标注才能不被理解为「换了尺子让结果好看」？
3. **诚实轴在 1.5 小时内做「一次修复 + 新校准 + 补判」现实吗？** 如果校准仍不过，是如实报告「不可用」，还是干脆不在今晚提这条轴？
4. **E 的负向依赖聚合口径，这个发现应该怎么呈现？** 它本身是一个有价值的方法学观察（0–3 级放大了单项差异），但也可能被读成「我们在为负面结果找解释」。有没有更稳妥的写法？
